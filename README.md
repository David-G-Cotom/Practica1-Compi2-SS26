# Practica1-Compi2-SS26
Primer practica del curso de Compiladores 2 - Universidad de San Carlos de Guatemala - CUNOC- Consiste en hacer una aplicacion que permita validar un lenguaje de programacion escrito en Latin, si el lenguaje de entrada es valido entonces se traducira a otro lenguaje en PigLatin - Tecnologias utilizadas: JDK 25 y ANTLR 4
